# Security Policy

🛡️ **Sentinel: Security is our top priority.**

We take the security of our applications and guide templates seriously. If you believe you have found a security vulnerability in this project, please report it immediately through the appropriate, non-public channels to help us keep this project secure.

## Supported Versions

Only the latest release of this repository is actively supported and receives security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes    |
| Older   | ❌ No     |

## Reporting a Vulnerability

Please **do NOT** open a public GitHub issue for security vulnerabilities. Instead, follow the responsible disclosure process:

1. **Submit a Private Vulnerability Report:**
   Use GitHub's built-in [Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/repository-security-advisories/configuring-private-vulnerability-reporting-for-a-repository) feature if enabled on this repository.
2. **Email Security Concerns:**
   If private vulnerability reporting is not available, please contact the maintainers directly.
3. **Information to Include:**
   - A detailed description of the vulnerability.
   - Step-by-step instructions (or a proof-of-concept script/exploit) to reproduce the behavior.
   - Potential security impact of the issue.

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a timely fix and release.

Thank you for helping keep this project and its community safe!
